# Bhakta Niwas Akkalkot — Final Website

Static website: no installation, build command, backend, or API key needed.

## Upload to GitHub
1. Extract this ZIP.
2. Upload index.html, assets/, .nojekyll, and README.md to your repository root. Upload the extracted files, not the ZIP itself.
3. For GitHub Pages: repository Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. For another static host: connect this repository and serve the repository root. Leave the build command empty.

The asset paths are relative so the site works on a GitHub Pages repository subpath and on a custom domain.

## Current features
Slim sticky header; two-banner hero; restored reception About Us image; desktop two-card room carousel; mobile vertically scrolling room cards; six-card gallery containing all seven restored photos; WhatsApp buttons.

## Before accepting enquiries
The temple address, phone, email, tariffs and room facilities still contain placeholders or sample content.
In index.html, set TEMPLE_WHATSAPP to your country-code-prefixed phone number using digits only (example format: 91XXXXXXXXXX).
The enquiry form prepares copyable text; it does not send messages or store submissions. Connect a form service or backend if you need delivery.
Google Fonts needs an internet connection; Georgia is the fallback.
Images were restored with AI, and reconstructed details may differ from the original photographs.
